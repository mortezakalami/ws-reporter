# گزارش‌گر ترافیک ویندزسکرایب (ws-reporter)

[English](README.md) | [فارسی](README.fa.md)

یک سرویس سبک و بدون نیاز به سرور (Serverless) روی **Cloudflare Workers** و **Workers KV** که مصرف ترافیک، حجم باقی‌مانده و تاریخ ریست اکانت‌های Windscribe را به‌صورت خودکار بررسی می‌کند و در پایان هر دور، گزارش کامل را در کانال تلگرام می‌فرستد.

## چرا این ابزار ساخته شده؟

وقتی تعداد اکانت‌های Windscribe زیاد باشد (مثلاً ۱۰ تا ۳۰ اکانت)، چک‌کردن همهٔ آن‌ها در یک لحظه باعث محدودیت نرخ (خطای 429) و بلاک‌شدن لاگین می‌شود. `ws-reporter` این مشکل را با یک صف چرخشی حل می‌کند: هر ۱۵ دقیقه فقط یک اکانت را بررسی و در KV ذخیره می‌کند و وقتی نوبت همهٔ اکانت‌های فعال تمام شد، گزارش کامل را به‌صورت خودکار به تلگرام می‌فرستد.

## قابلیت‌ها و ساختار فنی

- **بررسی پله‌ای با کرون (`*/15 * * * *`):** در هر اجرای ۱۵ دقیقه‌ای فقط یک اکانت چک می‌شود تا فشار و ریسک Rate Limit به حداقل برسد.
- **صف خودترمیم (Self-healing):** نتیجهٔ اکانت‌های بررسی‌شده در `WS_KV` نگهداری می‌شود. اگر وسط دور خطایی رخ دهد یا ربات به cooldown بخورد، در اجرای بعدی از اولین اکانت بررسی‌نشده ادامه می‌دهد.
- **مدیریت خطای 429 و Cooldown:** بین درخواست‌ها فاصله و jitter رعایت می‌شود، در خطاهای موقت دوباره تلاش می‌کند و در صورت محدودیت مداوم، ۳۰ دقیقه استراحت (cooldown) ثبت کرده و روی تکرار خطا به کانال هشدار می‌دهد.
- **پشتیبانی داخلی از تایید دو مرحله‌ای (TOTP 2FA):** تولید خودکار کد ۶ رقمی (RFC 6238 / HMAC-SHA1) با WebCrypto بدون نیاز به کتابخانهٔ خارجی.
- **رمزنگاری رمزها در KV:** با تنظیم `ENC_KEY`، رمز عبور اکانت‌ها با الگوریتم AES-256-GCM رمزنگاری و ذخیره می‌شود.
- **ارسال تکه‌تکه در تلگرام:** گزارش‌های طولانی به‌صورت خودکار در پیام‌های زیر ۳۵۰۰ کاراکتر تقسیم می‌شوند تا به سقف ۴۰۹۶ کاراکتر تلگرام نخورند.
- **بدون وابستگی اجرایی خارجی:** کل منطق ربات در [`src/worker.js`](src/worker.js) فقط با APIهای استاندارد وب و بایندینگ KV کلادفلر کار می‌کند.

## دستورات ربات تلگرام

فقط کاربرانی که آی‌دی آن‌ها در `ADMIN_IDS` ثبت شده باشد به دستورات دسترسی دارند:

| دستور | توضیح |
| --- | --- |
| `/start` یا `/help` | نمایش فهرست دستورات |
| `/add <user> <pass> [totp]` | افزودن یا ویرایش اکانت (پیام حاوی رمز را بلافاصله پاک می‌کند) |
| `/del <user>` | حذف اکانت و نتیجهٔ ذخیره شدهٔ آن |
| `/list` | نمایش لیست اکانت‌ها و وضعیت 2FA |
| `/check <user>` | بررسی فوری یک اکانت خاص |
| `/next` | اجرای دستی یک گام از صف |
| `/resync` | همگام‌سازی اشاره‌گر صف با اکانت‌های بررسی‌نشدهٔ دور جاری |
| `/report` | دریافت گزارش وضعیت فعلی تا این لحظه |
| `/status` | نمایش وضعیت کلی، پیشرفت دور، نوبت بعدی، آخرین اجرا و cooldown |

## مسیرهای HTTP

| مسیر | کاربرد | احراز هویت |
| --- | --- | --- |
| `POST /tg/webhook` | دریافت آپدیت‌های تلگرام | هدر `x-telegram-bot-api-secret-token` برابر با `WEBHOOK_SECRET` |
| `GET /setup?key=...` | ثبت خودکار آدرس Webhook در تلگرام | پارامتر `key` برابر با `WEBHOOK_SECRET` |
| `GET /run?key=...` | اجرای دستی یک گام چرخه | پارامتر `key` برابر با `WEBHOOK_SECRET` |
| `GET /` | بررسی سلامت ورکر | عمومی |

## راهنمای نصب و راه‌اندازی

۱. مخزن را کلون کنید و پکیج‌های توسعه را نصب کنید:

</div>

```bash
git clone https://github.com/mortezakalami/ws-reporter.git
cd ws-reporter
npm install
```

<div dir="rtl">

۲. در پنل Cloudflare یک **KV Namespace** بسازید و شناسهٔ آن را بردارید.

۳. فایل `.env.example` را به `.env` کپی کنید (فایل `.env` در `.gitignore` قرار دارد و وارد گیت نمی‌شود):

</div>

```bash
cp .env.example .env
```

<div dir="rtl">

۴. مقادیر داخل `.env` را تنظیم کنید:

| متغیر | وضعیت | توضیح |
| --- | --- | --- |
| `WS_KV_ID` | الزامی برای دیپلوی | شناسهٔ KV Namespace در کلادفلر |
| `ADMIN_IDS` | الزامی | آی‌دی عددی ادمین‌ها در تلگرام (با کاما جدا شوند) |
| `TELEGRAM_CHANNEL_ID` | الزامی | شناسهٔ کانال یا چت مقصد گزارش‌ها (مثلاً `-100...`) |
| `SHOW_PASSWORDS` | اختیاری | اگر `"true"` باشد رمزها در گزارش کامل نمایش داده می‌شوند (پیش‌فرض `"false"`) |
| `TELEGRAM_BOT_TOKEN` | الزامی (Secret) | توکن ربات تلگرام از BotFather |
| `ENC_KEY` | پیشنهادی (Secret) | کلید رمزنگاری پسوردها در KV |
| `WEBHOOK_SECRET` | الزامی (Secret) | رشتهٔ امنیتی برای محافظت از وب‌هوک و مسیرهای کنترلی |

۵. برای تست محلی یا گرفتن بیلد:

</div>

```bash
npm run dev
npm run build
```

<div dir="rtl">

۶. برای دیپلوی روی کلادفلر ابتدا لاگین کنید (`cf auth login`) و سپس دیپلوی را اجرا کنید:

</div>

```bash
npm run deploy
```

<div dir="rtl">

و سکرت‌ها را روی کلادفلر ثبت کنید:

</div>

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN --name ws-reporter
npx wrangler secret put ENC_KEY --name ws-reporter
npx wrangler secret put WEBHOOK_SECRET --name ws-reporter
```

<div dir="rtl">

۷. در پایان برای ثبت خودکار وب‌هوک تلگرام، آدرس زیر را یک بار باز کنید:

</div>

```text
https://<your-worker>.<your-subdomain>.workers.dev/setup?key=<YOUR_WEBHOOK_SECRET>
```

<div dir="rtl">

## نکات امنیتی

- در صورت تنظیم `ENC_KEY`، پسورد تمام اکانت‌ها با کلید SHA-256 و رمزنگاری AES-256-GCM در KV ذخیره می‌شوند.
- پس از ارسال دستور `/add`، ربات پیام حاوی رمز عبور را از چت حذف می‌کند.
- فایل‌های حاوی تنظیمات و سکرت‌ها (`.env`، `.dev.vars` و خروجی `.cloudflare/`) در `.gitignore` قرار دارند.
